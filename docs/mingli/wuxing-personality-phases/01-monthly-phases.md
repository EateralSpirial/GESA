# 十二月度五行性格相位

## 1. 基本原则

十二月度相位不再直接解释为十二个地支人格，而是解释为一年中十二个五行性格相位。

传统地支仍可作为月份入口，但最终解释对象是五行相位。

```text
地支 = 时间入口
五行相位 = 人格动力
```

## 3. 土的弱化与重写

传统命理会把辰、未、戌、丑视为土支。  
新版体系中，应弱化这一点。

四个传统土支不再是“土人格”，而是四个转化节点：

| 传统入口 | 旧读法 | 新读法 |
|---|---|---|
| 辰 | 土 | 木向火的孕育介质 |
| 未 | 土 | 火向金的锻造介质 |
| 戌 | 土 | 金向水的封存介质 |
| 丑 | 土 | 水向木的孕育介质 |

所以土的作用不是“压住其他五行”，而是：

```text
连接前后属性，使旧属性能够孕育新属性。
```

---

## 4. 月度相位的核心作用

月度相位决定一个人的长期底色，尤其是：

- 欲望类型；
- 世界温度体感；
- 对未来的默认判断；
- 对成长、显化、裁断、回流的偏好；
- 一生中最自然、最不费力的心理运动方向。

它更接近“底层欲望系统”，不宜直接等同于行动力。

行动入口需要看日内五行性格相位。
