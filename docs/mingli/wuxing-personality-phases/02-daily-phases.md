# 十二日内五行性格相位

> 本文档是理论建模草案，用于描述日内光热节律的象征结构。

## 1. 基本原则

日内相位不再机械挂靠十二时支，而是挂靠一天中的真实光热变化。

```text
太阳位置 + 温度滞后 + 活动节律 = 日内五行相位
```

## 3. 土性木

先知木具有木的未来性，也具有土的蕴含性。

```text
土性木 = 被土包裹的木，尚未出土，但已经向光。
```

它强调：

- 将出未出；
- 内部孕育；
- 外部尚未显形；
- 先在内部成胎，再向外展开。

---

## 4. 土性金

残照金与躁动金不是纯金。它们处于白日退场、夜间接管的转换阶段。

```text
土性金 = 金的边界、裁断、结算，与土的固持、执着、耐受结合。
```

残照金偏“光退而热未散”。  
躁动金偏“夜来而余热仍在”。

二者都带有执着、坚韧与不愿立刻松手的结构。

---

## 5. 日内相位的作用

日内相位主要用于描述行动入口：

- 如何启动；
- 如何反应；
- 如何进入外部世界；
- 欲望如何通过身体和节律进入行动。

月度相位更像长期欲望，日内相位更像即时行动。
