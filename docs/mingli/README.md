## 体系修订

旧版本倾向于把体系挂靠在“月支 × 时支”的双十二地支结构上。新版不再把人格系统直接挂靠到地支，而是改为：

```text
月度五行性格相位 × 日内五行性格相位 = 144 种人格结构
```

其中：

- 十二月支只作为年度相位入口，不再作为最终人格标签。
- 十二时支只作为日内相位入口，不再作为最终人格标签。
- 五行被理解为不同的性格运动方式。
- 土不再作为月支中的独立人格属性，而是作为前后季节的连接、孕育、转化与承载机制。
