# 07. 五大界面

> Version: 0.1  
> Parent: [GESA 企业空间系统](./README.md)

---

## 1. 界面总览

企业空间系统第一版包含五个主要界面：

```text
1. 对象聊天
2. 日程表和功能库
3. 执行器
4. 组织架构管理和查看
5. 用户主页
```

---

## 2. 对象聊天

人和 Agent 都是对象。

对象聊天允许用户与以下对象沟通：

```text
1. 自己的 Agent 对象
2. 同级对象
3. 直属上司对象
4. 下属对象
5. 被授权沟通的部门对象
6. 被授权沟通的空间对象
```

每个对象聊天可拥有多个线程：

```text
1. 默认置顶线程
2. 自定义线程
3. 临时任务线程
```

自定义线程应支持双方同意后开启或关闭。

---

## 3. 日程表和功能库

日程表默认采用七日视图。

默认时间范围：

```text
07:00 - 19:00
```

用户可自定义每日起止时间。

规则：

```text
1. 用户可以将日程对象拖入时间格。
2. 一个时间段默认只能安排一个日程对象。
3. 日程对象以用户权限执行。
4. 日程对象可以绑定一个或多个脚本。
```

功能库包括：

```text
1. 私有日程库
2. 日程模板库
3. 私有脚本库
4. 公共脚本库
```

---

## 4. 执行器

执行器展示和管理用户布置的任务。

任务类型：

```text
1. 浏览器任务
2. 代码任务
3. 企业内部脚本任务
4. 文件生成任务
5. 综合任务
```

执行器需要展示：

```text
1. 任务状态
2. 执行对象
3. 权限上下文
4. 执行日志
5. 结果文件
6. 审计摘要
```

对于拥有相应权限的对象，可展示项目自我迭代状态。

---

## 5. 组织架构管理和查看

该界面展示层级、方向、格子和部门。

普通员工：

```text
1. 查看公司架构。
2. 查看自己所属部门。
3. 查看自己可见空间。
4. 只读为主。
```

部门管理员：

```text
1. 管理本部门员工信息。
2. 管理本部门空间。
3. 管理被完整覆盖的下级部门空间。
4. 发起资源授权。
5. 查看部门审计摘要。
```

CEO / 超级管理员：

```text
1. 查看完整企业结构。
2. 管理所有层级、方向、格子和部门。
3. 管理最高权限管理器。
4. 查看全局审计摘要。
```

---

## 6. 用户主页

用户主页显示个人工作区。

功能：

```text
1. 用户信息
2. 所属部门
3. 权限摘要
4. 个人文件系统
5. Agent Team 设置
6. 日程设置
7. 脚本设置
8. 聊天线程管理
9. 工作区显示设置
10. 审计摘要
```

---

## 7. UI 设计原则

```text
1. 企业用户只看到自己能理解的对象。
2. 权限复杂度通过组织权限图可视化。
3. 个人工作区与共享空间明确分离。
4. 执行器必须展示任务状态和结果。
5. 所有高价值操作都应能追溯到对象、权限和审计记录。
```
