# 01. 企业空间系统定位与边界

> Version: 0.1  
> Parent: [GESA 企业空间系统](./README.md)

---

## 1. 定位

GESA 企业空间系统是企业用户面对 GESA 时看到的操作层。

它的职责不是解释代码如何运行，而是解释企业内部的对象如何被组织、授权、协作和执行。

```text
企业空间系统 = 企业侧操作入口 + 权限资源中枢 + 组织可视化界面。
```

---

## 2. 两种访问形态

第一版优先支持：

```text
1. 浏览器可访问的 Web 服务。
2. 可渐进增强为 PWA。
3. 后续可扩展为微信小程序等轻量级入口。
```

Web / PWA 是主入口，小程序适合作为轻量入口和移动端通知入口。

---

## 3. 三个重要概念

```text
1. 组织权限图
2. 共享空间
3. 个人工作区
```

其中：

```text
组织权限图：描述 CEO、最高权限管理器、层级、方向、格子、部门、部门首脑和授权关系。
共享空间：描述格子空间、部门空间、方向空间、层级空间、全局空间。
个人工作区：描述个人可见的聊天、日程、任务、脚本、文件、Agent Team 和设置。
```

---

## 4. 与开发者架构层的边界

企业空间系统使用企业语言：

```text
部门、层级、方向、格子、空间、名单、授权、对象、Agent、日程、任务。
```

开发者架构层使用工程语言：

```text
Entity、Space、Resource、Permission、Operation、Audit、API、Schema、Service、Engine。
```

两者通过底层对象模型连接。

---

## 5. 核心判断

GESA 不应只提供传统后台管理界面。它应该提供一个企业空间系统，让企业中每个对象都能在自己的权限范围内看到、沟通、安排、执行和管理资源。

```text
用户看到的是空间。
系统执行的是权限。
Agent 使用的是上下文与工具。
审计记录的是每一次对象操作。
```
