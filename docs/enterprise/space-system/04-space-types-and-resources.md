# 04. 空间类型与资源对象

> Version: 0.1  
> Parent: [GESA 企业空间系统](./README.md)

---

## 1. 空间类型

企业空间系统包含六类空间：

```text
SpaceObject
├── PersonalWorkspace
├── CellSpace
├── DepartmentSpace
├── DirectionSpace
├── LevelSpace
└── GlobalSpace
```

---

## 2. 个人工作区

个人工作区绑定到单个实体对象。

```text
PersonalWorkspace(entity_id)
```

它主要承载个人可见的聊天、日程、任务、脚本、设置和个人文件系统。

---

## 3. 格子空间

每个格子拥有自己的内部空间。

```text
CellSpace(level, direction)
```

格子空间可放置：

```text
1. 文件系统对象
2. 知识库对象
3. 代码执行器对象
4. Agent Team
```

格子空间更窄，主要服务于特定层级和特定方向。

---

## 4. 部门空间

每个部门拥有自己的公共空间。

```text
DepartmentSpace(department_id)
```

部门空间可放置：

```text
1. 文件系统对象
2. 知识库对象
3. 数据库对象
4. Agent Team
5. 代码执行器对象
6. 部门名单对象
7. 授权器对象
8. 部门管理对象
```

部门空间的对象种类多于格子空间。

---

## 5. 方向空间

方向空间表示某一个业务方向的横向知识与资源。

示例：

```text
财务方向空间
采购方向空间
人力资源方向空间
Agent 资源方向空间
```

方向空间适合放置跨层级共享的规范、模板、流程和知识库。

---

## 6. 层级空间

层级空间表示同一管理高度下的公共资源。

示例：

```text
L7 总管理层空间
L4 部门管理层空间
L1 基层执行层空间
```

层级空间适合承载同级培训、通告、模板和横向协作资源。

---

## 7. 全局空间

全局空间是企业级公共空间。

可放置：

```text
1. 全局公告
2. 企业制度
3. 全局知识库
4. 全局脚本库
5. 全局 Agent Team
6. 全局审计入口
```

---

## 8. 所有共享空间可拥有的对象

```text
1. 共享空间管理器
2. 文件系统对象
3. 代码执行器对象
4. Agent Team
5. 数据库对象
6. 知识库对象
7. 脚本库对象
8. 任务队列对象
9. 审计日志对象
```

---

## 9. 部门空间独有对象

```text
1. 部门管理对象
2. 名单对象
3. 授权器对象
```

其中：

```text
部门管理对象：由部门首脑负责。
名单对象：原则上公示。
授权器对象：负责部门空间内的授权记录和权限转交。
```

---

## 10. 空间资源原则

```text
1. 资源必须挂载到空间。
2. 资源权限由空间权限和资源自身权限共同决定。
3. 部门空间可以管理被完全笼罩的下级部门空间。
4. 上级部门可向同级、下级或特定部门授权资源读写能力。
5. 个人工作区不拥有长期个人向量知识库和个人数据库。
```
